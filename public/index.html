Where the model runs

Inkwell is built for a model on your own machine — private, unmetered, and yours. A cloud key is here only for devices that can't run one.

On your machine — Ollama recommended

Cloud models are billed per word by the provider and your manuscript is sent to them. The key is stored in settings.json on this machine and is never sent to the browser.

Illustration

For picture books. Your local model writes the prompt; a drawing engine on this machine renders it. Inkwell can install that engine for you — one button, no Python, no separate program — and the pictures are saved inside the book’s own folder.
